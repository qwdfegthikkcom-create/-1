# مركز البصرة لطب وتجميل الأسنان — موقع ويب مقترح

موقع تعريفي احترافي باللغة العربية (RTL) لـ **مركز البصرة لطب وتجميل الأسنان** في البصرة،
وهو مركز يتابعه نحو 363 ألف شخص على إنستغرام ولا يملك موقعًا رسميًا.

📄 **سبب اختيار هذه العيادة:** راجع [RESEARCH.md](RESEARCH.md) (مقارنة بين 10 عيادات في بغداد والبصرة وأربيل).

> ⚠️ هذا **تصميم مقترح (نموذج عرض)** يُقدَّم للمركز. البيانات مأخوذة من حساباته العامة، وصورة «قبل/بعد» رسم توضيحي وليست حالة حقيقية.
> قبل الإطلاق يجب تأكيد المعلومات مع المركز (انظر القسم 4 في ملف البحث).

## المميزات

- تصميم عصري وجذاب، متجاوب بالكامل مع الهاتف والحاسوب.
- واجهة رئيسية بحركات خفيفة وإحصائيات متحركة.
- 8 بطاقات خدمات (زراعة، ابتسامة هوليود، تقويم، تبييض، عصب، زركون، أطفال، جراحة).
- مقارنة **قبل/بعد** تفاعلية بالسحب.
- رحلة العلاج بأربع خطوات، وأسئلة شائعة.
- **نموذج حجز يرسل الطلب مباشرة إلى واتساب المركز** برسالة جاهزة.
- خريطة Google وزر واتساب عائم.
- تحسين محركات البحث: وسوم Meta و Open Graph وبيانات منظمة `schema.org/Dentist`.
- بدون أي مكتبات أو خطوات بناء — HTML + CSS + JavaScript فقط.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر المجاني على GitHub Pages

1. من صفحة المستودع: **Settings → Pages**.
2. في **Source** اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
3. بعد دقيقة سيظهر الرابط بالشكل: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

## هيكل الملفات

```
index.html          الصفحة الرئيسية
assets/styles.css   التصميم والألوان
assets/script.js    القائمة، الحركات، قبل/بعد، نموذج الحجز
assets/favicon.svg  أيقونة الموقع
RESEARCH.md         بحث اختيار العيادة
```

## التعديل السريع

- **رقم الواتساب:** المتغير `WHATSAPP` في أول `assets/script.js` وروابط `wa.me` و `tel:` في `index.html`.
- **الألوان:** المتغيرات في أعلى `assets/styles.css` (`--teal`، `--ink`، `--gold`…).

## إضافة صور من منشورات العيادة (قسم «من أعمالنا»)

القسم مخفي تلقائيًا إلى أن تضيف صورًا. في أول `assets/script.js`:

- **منشورات إنستغرام:** من التطبيق اضغط ⋯ ← مشاركة ← نسخ الرابط، ثم ضع الروابط هنا:
  ```js
  const INSTAGRAM_POSTS = [
    "https://www.instagram.com/p/XXXXXXXX/",
  ];
  ```
  تظهر المنشورات عبر التضمين الرسمي لإنستغرام (تعمل بعد نشر الموقع، وليس عند فتح الملف محليًا).
- **صور من العيادة نفسها:** ضعها في `assets/gallery/` وأضفها هكذا:
  ```js
  const GALLERY_IMAGES = [
    { src: "assets/gallery/case-1.jpg", alt: "ابتسامة هوليود – زركون" },
  ];
  ```
